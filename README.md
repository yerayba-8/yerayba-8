## 📈 Proyectos Destacados

### 🎵 [TikTok Trend Predictor: Data Science & MLOps Pipeline](https://github.com/yerayba-8/tiktok-trend-predictor)
Un flujo completo (End-to-End) automatizado para predecir el éxito de interacción (likes de TikTok) de canciones basado en sus atributos técnicos de audio.
* **Fase de Datos:** Análisis exploratorio (EDA) y matriz de correlación visualizada en Jupyter Notebook utilizando Pandas y Seaborn.
* **Modelado:** Entrenamiento de un algoritmo *Random Forest Regressor* logrando una precisión métrica de $78.88\%$ en el coeficiente de determinación ($R^2$).
* **Fase MLOps:** Paquetizado del modelo y despliegue en producción como un microservicio local mediante una API con FastAPI para procesar peticiones JSON en tiempo real.
